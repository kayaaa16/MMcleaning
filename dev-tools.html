🔧 修補：補回缺失的分類標籤

如果你發現任務卡上的分類標籤（例如「特殊」「場租AB」）還在，但側邊上方的 tab 不見了，代表 settings.categories 在過去被覆蓋過。按下方按鈕會掃描所有 templates 的 category 欄位，把不在 categories 陣列裡的補回去（追加在最後，**不改動既有順序**）。

💾 下載備份

把全部 collection（settings / templates / tasks / shifts）打包成一個 JSON 檔，存到下載資料夾。建議養成「每週手動備份一次」的習慣。

♻️ 從備份還原

選一個之前下載的 JSON 檔，會用 合併模式 寫回 Firestore — 同 ID 的文件會被覆蓋，不在備份裡的文件不會被刪。

⚠️ 此操作會立即寫入雲端，請先確認你選的檔案來自正確的專案、時間點也正確。建議在還原前**先按上面「下載備份」做一次當下備份**，這樣萬一還原錯了也能再還原回來。
